# Android 재생 관찰 PoC 계획

- 상태: 계획
- 관련 결정: [`ADR 0002`](../../decisions/0002-share-based-track-import.md)
- 결과: 없음

## 검증 질문

사용자가 권한을 부여한 실제 Android 기기에서 지원 음악 앱의 공개 재생 정보를
관찰하고, 신뢰할 수 없는 정보에는 실시간 연동 없는 읽기 방식으로 폴백할 수 있는가?

## 선행 조건

- 실제 Android 기기에서 실행 가능한 최소 재생 관찰 구현이 있어야 한다.
- 시험할 음악 앱, 권한, 신뢰 가능한 상태의 판정 기준이 정의되어야 한다.

## 범위

- 권한 허용과 거부
- 곡 변경, 재생, 일시정지와 탐색 위치 변화
- 메타데이터 누락, 오래된 상태와 서로 충돌하는 정보
- 소스 앱 종료, 전환과 백그라운드 상태
- 신뢰할 수 없는 경우의 읽기 방식 폴백

## 절차 초안

1. 권한을 거부한 상태에서 기본 공유 가져오기와 읽기 경험이 유지되는지 확인한다.
2. 권한을 허용하고 지원 음악 앱에서 곡을 재생한다.
3. 곡 변경, 재생·일시정지와 위치 탐색을 수행해 관찰된 상태와 시각을 기록한다.
4. 소스 앱을 전환하거나 종료하고 관찰 정보의 갱신·만료 동작을 확인한다.
5. 메타데이터나 재생 시각을 신뢰할 수 없는 조건을 만들고 폴백을 확인한다.

## 통과 조건

- 권한 거부가 공유 가져오기와 기본 읽기 경험을 막지 않는다.
- 곡과 재생 시각을 신뢰할 수 있는 조건에서만 실시간 강조가 활성화된다.
- 누락되거나 오래된 정보가 현재 재생 상태로 표시되지 않는다.
- 신뢰할 수 없을 때 사용자에게 상태를 명확히 알리고 읽기 방식으로 폴백한다.

## 기록할 환경과 증거

- 기기 모델, Android 버전, 음악 앱과 Lymo 버전
- 권한 상태, 소스 앱 상태와 단계별 실제 관찰
- 위치 정확도는 관찰 방법과 허용 오차를 함께 기록

이 문서는 계획이며 실제 기기 지원이나 정확한 실시간 동기화를 증명하지 않는다.
