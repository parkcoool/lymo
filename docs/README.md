# Lymo 개발 문서

이 디렉터리는 Lymo의 현재 방향, 결정, 미결 질문과 검증 증거를 관리합니다. 같은 정보를 여러 문서에 반복하지 않고 아래 정본에서 관리합니다.

## 문서 지도

| 문서 | 역할 |
| --- | --- |
| [`../AGENTS.md`](../AGENTS.md) | 장기 제품 정의, 신뢰·도메인 경계와 저장소 최상위 원칙 |
| [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md) | 변경 가능한 기술 방향, 지원 범위와 검증 상태 |
| [`OPEN_QUESTIONS.md`](OPEN_QUESTIONS.md) | 아직 결정하거나 검증해야 하는 질문 |
| [`DEVELOPMENT_CONVENTIONS.md`](DEVELOPMENT_CONVENTIONS.md) | 개발, 테스트, 문서, Git과 PR 규칙 |
| [`decisions/`](decisions/) | 확정된 중요한 결정과 대안, 결과를 설명하는 ADR |
| `contracts/` | 플랫폼 공통 인터페이스, 데이터 형식과 픽스처. 첫 계약 결정 시 생성 |
| [`validation/`](validation/) | 실제 기기 PoC 계획, 기록 방법과 정제된 결과 |
| [`meetings/`](meetings/) | 결정 과정의 역사적 요약. 현재 사실은 해당 정본 문서에서 확인 |

상세 설계는 성격에 따라 ADR, 계약, 검증 기록 또는 구현 모듈 가까이 둡니다. 회의록을 현재 제품 상태의 근거로 단독 사용하지 않습니다.

## 공개 문서 원칙

이 저장소에 커밋하는 문서는 공개되어 Git 기록에 계속 남을 수 있다고 간주합니다. 정본, 결정, 구현 계약, 재현 가능한 절차, 정제된 검증 결과와 축약된 회의 기록만 포함합니다.

다음 정보는 커밋하지 않습니다.

- 비밀 정보, 인증정보, 개인·계정·기기 식별 정보
- 제공업체와의 비공개 연락이나 협상 내용
- 공개가 승인되지 않은 비용, 수익, 출시 일정 등 사업 정보
- 악용 가능한 미공개 보안 취약점의 상세 절차
- 전체 공유 URL, 전체 가사, 원본 로그와 대용량 화면 녹화
- 결정과 무관한 대화 전문이나 개인 메모

민감한 내용이 결정 이해에 꼭 필요하면 임의로 생략해 기록을 왜곡하지 않습니다. 공개 가능한 요약을 합의하거나 게시를 중단하고 별도 비공개 공간에서 다룹니다.
