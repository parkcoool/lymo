# Lymo

**가사 너머의 이야기와 감정을 읽는 음악 감상**

Lymo는 음악 앱에서 가져온 곡을 가사, 번역, 구절별 맥락, 문화적 배경과
AI 해석을 통해 더 깊이 읽고 이해하도록 돕는 크로스플랫폼 음악 리더를
지향합니다.

> Lymo는 현재 V2 초기 설계와 실제 기기 검증을 준비하고 있습니다. 아직
> 설치하거나 사용할 수 있는 제품이 아니며, 아래 내용은 개발 목표입니다.

## 목표 경험

1. Spotify나 Apple Music 같은 음악 앱에서 개별 곡을 Lymo로 공유합니다.
2. Lymo가 곡을 확인하고 나중에도 다시 열 수 있도록 가져오기를 보존합니다.
3. 재생 연동 여부와 관계없이 가사와 곡의 맥락을 읽고 탐색합니다.

Android와 iOS 모두 같은 사용자 경험을 목표로 하지만, 각 운영체제가 공식적으로
지원하는 기능과 제약 안에서 구현합니다. 공유한 곡을 가져오는 행위가 실시간 재생
동기화를 보장하지는 않습니다.

## 정보에 대한 약속

Lymo는 검증된 사실, 라이선스가 부여된 데이터와 제공업체 데이터, 커뮤니티 기여,
AI 추론을 서로 구분하는 제품을 지향합니다. AI 해석을 검증된 사실처럼 제시하지
않으며, 가사와 외부 데이터는 권리와 제공업체 정책을 확인한 뒤 다룹니다.
